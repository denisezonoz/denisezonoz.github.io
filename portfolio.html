Application Intelligence Dashboard Agent

GE Vernova · Summer 2026

  • What it does: Brings AWS Resiliency Hub and AWS DevOps data into one conversational interface, so teams can ask about application health and resiliency in plain language instead of digging through separate dashboards.
  • How it's built: Full-stack agent on GE Vernova's internal AMP platform, with a Python backend and a TypeScript frontend. The split-screen layout pairs a chat panel with a live findings dashboard.
  • Impact: Built for the CTO team, with expansion underway to Power business teams, cutting down manual research for application owners.

Boba Shop Point-of-Sale System

CSCE 331 Software Engineering · Fall 2026

  • What it does: A point-of-sale and store management system for a boba shop: drink ordering with sweetness, ice, and topping options, plus inventory tracking, restock alerts, employee management, and sales reports.
  • How it's built: Java and JavaFX on a 10-table PostgreSQL database, built by a 5-person team in Scrum sprints tracked on Jira.
  • My part: Wrote Python generators that seed the database with 170K+ simulated orders, and built the manager restock report and employee management view.
