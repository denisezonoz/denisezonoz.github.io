# denisezonoz.github.io

My personal website: projects, experience, and a bit about me.

**Live site:** https://denisezonoz.github.io

## Pages

- **Home**: intro and contact links
- **Portfolio**: projects from my GE Vernova internship, coursework, and Aggie Coding Club
- **Activities**: leadership in the Society of Women Engineers and other involvement
- **Qualifications**: resume and skills

## Built with

Plain HTML, CSS, and JavaScript, hosted on GitHub Pages. The site has two hand-built themes, **Bow** and **Flower**. Switch with the toggle at the top of any page, and the site remembers your choice.

Some decorative illustrations were generated with AI (Figma AI and Gemini).
